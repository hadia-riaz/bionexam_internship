# Week 1 — 16S rRNA Sequence Analysis of Pseudomonas putida

## Overview

During Week 1 of the Bionexam internship, I performed a basic bioinformatics workflow involving sequence retrieval, BLAST analysis, multiple sequence alignment, and phylogenetic analysis.

## Workflow

1. Retrieved the 16S rRNA gene sequence of *Pseudomonas putida* from NCBI.
2. Downloaded the sequence in FASTA format.
3. Performed nucleotide BLAST analysis.
4. Selected the top five sequences from the BLAST results.
5. Performed Multiple Sequence Alignment (MSA) using ClustalW.
6. Constructed a phylogenetic tree using PhyML Bootstrap.
7. Downloaded the resulting phylogenetic tree in PNG format.

## Tools Used

- NCBI
- Nucleotide BLAST
- ClustalW
- PhyML
- FASTA
